# Degree/diameter graph `(Delta, D) = (4, 5)`

Construct the largest simple undirected graph with maximum degree four and
diameter at most five. The external evaluator checks the edge list, degrees,
connectivity, and every shortest-path distance exactly. The Moore bound is 485.

The June 2024 [degree/diameter table and survey](https://arxiv.org/abs/2406.18994)
records 364 vertices for this cell; it is not marked optimal. The seed is the
35-vertex Cartesian product `C5 square C7`, which is 4-regular with diameter 5.
