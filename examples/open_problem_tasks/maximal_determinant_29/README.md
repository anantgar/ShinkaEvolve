# Maximal determinant, order 29

Construct a `29 x 29` `{+1,-1}` matrix with maximum absolute determinant. The
external evaluator uses an exact Bareiss determinant and scores its logarithm.
The maintained [order-29 record page](https://maths-people.anu.edu.au/~brent/maxdet/order29/)
labels the leading Gram matrix conjecturally optimal and gives determinant
`320 * 7^12 * 2^28` for its `{+1,-1}` decomposition.

The seed `2I-J` has exact determinant `27 * 2^28`; it is deliberately valid but
well below the public record.
