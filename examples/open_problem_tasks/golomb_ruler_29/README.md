# 29-mark Golomb ruler

Construct 29 increasing integer marks whose 406 positive pairwise differences
are all distinct, minimizing the last mark. Verification is exact and quadratic.

[distributed.net's OGR-28 completion](https://blogs.distributed.net/2022/11/23/03/28/bovine/)
reports that proving the 28-mark optimum took about 8.5 years and that OGR-29
was not planned because of the projected search scale. The benchmark therefore
measures construction quality; it does not pretend an evolution run proves
optimality. The valid Mian-Chowla seed has length 1,158.
