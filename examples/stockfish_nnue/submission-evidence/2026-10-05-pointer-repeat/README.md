# Independent-boot pointer confirmation

This plan is frozen before primary candidate timing. Graviton3 and Graviton4
repeat the GCC pointer main/deeper comparisons and their A/A controls on fresh
boots with independently generated baseline PGO profiles. Launch follows the
primary Intel code-identity preflight. No favorable retries are permitted.

The [runtime bound](runtime-bound.json) was extended to allow the unchanged
fixed budgets to complete; no worker restart or statistical rule change.

The first [complete repeat-boot receipts](completed-results.json) are published
for Graviton3; Graviton4 is still running. `scope_qualified` means a complete
operator comparison with matching A/A and immutable common profiles. The raw
driver retains `supports_speed_claim=false`: no evolution fitness pool or Elo
is qualified by these measurements.
